# EmRec


EmRec is a python open source project made for immediate emergency recording!

## Installation

Use the package manager [pip](https://pip.pypa.io/en/stable/) to install all needed packages (listed below).

```bash
pip install pystray pillow plyer keyboard pyautogui opencv-python numpy pyaudio customtkinter
```

## Usage

It is commonly used in recording in emergency situation, like [Medal](https://medal.tv/) (is another software that records in situation when you maybe like need evidence etc..) it does the same job!
